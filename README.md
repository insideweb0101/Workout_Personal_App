# Workout Personal App

A simple mobile-friendly workout planner with exercise guidance and workout completion tracking.

## Run the app
1. Install Node.js from https://nodejs.org/ (LTS version).
2. In this folder, open a terminal and run `npm install`.
3. Run `npm run dev` and open the local address it prints.

The app saves completion marks in the browser on that device. Exercise photos require an internet connection. Starting weights are only general examples; choose a comfortable load that allows controlled form, and ask a qualified trainer for individual guidance.
